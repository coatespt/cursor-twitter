

Your config file should be ./config/config.yaml

However, if you are working on another machine, a bunch of small thing, e.g. pathnames
may be different. 

Copy your config.yaml to the appropriate file name when you are going to commit.
Be sure to also port any new or significant values to the other machine files and/or put them here.

E.g.  	config.yaml is the working file.

I keep  config.yaml.76   for the System76 laptop
and 	config.yaml.imac for the iMac.
