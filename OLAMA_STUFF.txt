from the iMac.

    Get the laptop's IP address. Open a terminal on your Ubuntu laptop and run the following command to find its local IP address:
    bash

    ip addr show | grep inet

    Use code with caution.

Look for the IP address starting with 192.168. or 10. on the network interface (e.g., eth0 or wlp4s0). For example, 192.168.1.50.
Edit the Ollama systemd service. Ollama runs as a service on Ubuntu. Edit its service configuration to allow remote connections.
bash

sudo systemctl edit ollama.service

Use code with caution.
This command opens a new editor for overrides.
Set the OLLAMA_HOST variable. Add the following lines to the editor. 0.0.0.0 tells Ollama to listen on all network interfaces..
ini

[Service]
Environment="OLLAMA_HOST=0.0.0.0"

Use code with caution.
Save and close the editor. In nano, use Ctrl+X, then Y, then Enter.
Reload the service and restart Ollama.
bash

sudo systemctl daemon-reload
sudo systemctl restart ollama

Use code with caution.
Allow traffic through the firewall. If the Ubuntu firewall (ufw) is active, you need to open port 11434 for Ollama.
bash

sudo ufw allow 11434/tcp
sudo ufw reload

Use code with caution.
 

Part 2: Write the Go program on your iMac
The Go program sends HTTP requests to the Ollama API on the Ubuntu laptop, using its IP address. The official Go client library simplifies this process. 

    Initialize your Go project on your iMac.
    bash

    mkdir go-ollama-client
    cd go-ollama-client
    go mod init go-ollama-client

    Use code with caution.

Add the Ollama Go API client.
bash

go get github.com/ollama/ollama/api

Use code with caution.
Write the client code. Create a file named main.go and add the following content. Replace <your_ubuntu_ip> with the actual IP address found in Part 1.
go

package main

import (
	"context"
	"fmt"
	"log"

	"github.com/ollama/ollama/api"
)

func main() {
	// Define the remote Ollama host address
	host := "<your_ubuntu_ip>:11434"

	// Create an Ollama client
	client, err := api.NewClient(host, nil)
	if err != nil {
		log.Fatal(err)
	}

	// Define the chat request
	req := &api.ChatRequest{
		Model: "llama3", // Ensure this model is downloaded on the Ubuntu laptop
		Messages: []api.Message{
			{Role: "user", Content: "Tell me a fun fact about Go programming."},
		},
	}

	// Send the request and handle the response
	res, err := client.Chat(context.Background(), req)
	if err != nil {
		log.Fatal(err)
	}

	// Print the response content
	fmt.Println("Ollama Response:", res.Messages[0].Content)
}

Use code with caution.
Run the Go program.
bash

go run main.go

Use code with caution.

    The program connects to the Ollama instance on the Ubuntu laptop and prints the model's response to the terminal on your iMac.

Putting it all together
By default, Ollama does not have a built-in graphical browser interface. It is a command-line tool that serves models via an API
. To interact with Ollama through a web UI, you can use a separate, community-developed application. The most popular choice is Open WebUI, which offers a user-friendly chat interface similar to ChatGPT. 
How to set up Open WebUI
To get a web interface running on your Ubuntu laptop, the recommended method is to use Docker. 
On your Ubuntu laptop

    Install Docker. If you don't already have Docker installed, follow the official instructions for your Ubuntu version.
    Install Open WebUI. Run the following Docker command in your terminal. This command will pull the Open WebUI image and run it in a container, connecting to your already running Ollama instance.
    bash

    sudo docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main

    Use code with caution.

Access the web UI from your iMac. Since you already configured Ollama to accept remote connections, the Open WebUI container can also be accessed remotely.

    Open a web browser on your iMac.
    Navigate to the Ubuntu laptop's IP address and the port for Open WebUI: http://<your_ubuntu_ip>:3000.

Register and start chatting. The first time you visit the Open WebUI page, you'll be prompted to create an admin account. After signing up, you can start interacting with the Ollama models you have installed. 

Alternative for Ollama + WebUI
For a simpler, all-in-one approach, you can run a single Docker command that bundles both Ollama and Open WebUI together. If you haven't installed any models yet, this method is very convenient. 

    First, stop and remove your current Ollama service to avoid conflicts.
    bash

    sudo systemctl stop ollama
    sudo systemctl disable ollama

    Use code with caution.

Next, run the following Docker command on your Ubuntu laptop:
bash

sudo docker run -d -p 3000:8080 --gpus=all -v ollama:/root/.ollama -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:ollama

Use code with caution.
This command downloads both Ollama and Open WebUI and runs them in a way that handles the internal networking for you.
Finally, access the web UI from your iMac via http://<your_ubuntu_ip>:3000 as before.
