# Language Detector

A standalone Go program for fast language detection on CSV tweet files.

## Overview

This program reads CSV files generated by the Python parser, detects the language of each tweet's text content, and updates the language field (last field) with the detected language code.

## Why Use This?

- **Much faster** than Python's `langid` library (typically 10-100x faster)
- **More accurate** than the original language field in Twitter JSON
- **Standalone processing** - can be run independently of the main pipeline
- **Batch processing** - processes all CSV files in a directory

## Usage

```bash
# Build the program
go build -o language_detector language_detector.go

# Run on a directory of CSV files
./language_detector -input /path/to/csv/files -output /path/to/output/directory
```

## Workflow

1. **Parse JSON to CSV** (fast, no language detection):
   ```bash
   python parser/parser.py input_dir output_dir --no-language-detect --num-workers 4
   ```

2. **Detect languages** (fast Go program):
   ```bash
   ./language_detector -input output_dir -output output_dir_with_langs
   ```

3. **Use the updated CSV files** in your main pipeline

## Performance

- **Speed**: Typically 1000-5000 tweets/second (vs ~250/second with Python langid)
- **Languages**: Supports 20+ common languages
- **Accuracy**: Uses low-accuracy mode for speed, but still much better than original Twitter language field

## Supported Languages

- English, Spanish, French, German, Portuguese, Italian
- Dutch, Swedish, Danish, Finnish, Polish, Russian
- Japanese, Chinese, Korean, Arabic, Hindi, Turkish, Hebrew

## Configuration

The program uses the `lingua-go` library with:
- **Low accuracy mode** for maximum speed
- **Common languages only** to reduce false positives
- **Minimum text length** of 10 characters for detection

## Integration with Main Pipeline

After running the language detector, you can use the updated CSV files with `language_filter: "en"` in your config.yaml for much faster processing, since the language field will be accurate.
